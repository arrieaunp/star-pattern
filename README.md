# ⭐ Star Pattern Generator

A simple frontend app built with React that displays a reverse pyramid star pattern based on user input.

## ✅ Features

- Input a number (e.g. 5)
- Display pattern of stars from 1 to input, then reverse:
*
**
***
****
*****
****
***
**
*

## 🛠 Tech Stack

- HTML / CSS
- JavaScript with [React / Vue / Angular]
